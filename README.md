# 📊 Bank Marketing Analytics

An end-to-end data analytics project that analyzes a bank marketing campaign using Python, PostgreSQL, Microsoft Fabric, and Power BI.

The objective is to identify customer segments with the highest subscription rates and provide business insights to improve future marketing campaigns.

---

## 🚀 Project Overview

This project follows the complete analytics workflow:

1. Data cleaning and exploration using Python
2. SQL analysis in PostgreSQL
3. Interactive dashboard development in Power BI
4. Business insights and recommendations

## 💡 Key Insights

- Overall subscription rate is approximately 11.7%.
- Students and retired customers achieved the highest conversion rates.
- Older customers generally have higher average account balances.
- Previous successful campaign outcomes strongly increase future subscription rates.
- Marketing performance varies significantly across customer demographics.
